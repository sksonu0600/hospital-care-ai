# CareGraph Hospital AI — UV + LangGraph POC (No RAG)

## Features
- UV dependency management (`pyproject.toml`; `uv.lock` is generated by `uv sync`)
- `.env.example`; copy it to `.env`. `.env` is ignored by Git.
- Streamlit dashboard, synthetic demo cases, and manual synthetic input
- LangGraph nodes for intake validation, demo triage routing, summary, differential considerations, medication-safety review, and report generation
- No RAG, no vector database, no external medical knowledge retrieval
- No API key required; this version uses transparent demo logic

## Safety
Educational software demo only, not a medical device and not clinically validated. Use synthetic data only. Keyword red-flag routing is not a validated triage system. Differential considerations are not diagnoses. No drug or dose is prescribed. Real use requires clinician governance, validation, privacy/security review, and legal/regulatory assessment.

## Requirements
Python 3.11+ and UV. Install UV using https://docs.astral.sh/uv/getting-started/installation/

## Run — macOS/Linux
```bash
uv sync
cp .env.example .env
uv run streamlit run src/caregraph_hospital_ai/app.py
```

## Run — Windows PowerShell
```powershell
uv sync
Copy-Item .env.example .env
uv run streamlit run src/caregraph_hospital_ai/app.py
```
Open the local URL shown, usually http://localhost:8501.

## Test

## Agent responsibilities
1. `intake_validation`: required-field checks and explicit unknowns; not authentication.
2. `triage_demo`: toy keyword route only; not for real emergency detection.
3. `summary_agent`: summarizes entered facts and marks absent information.
4. `differential_agent_demo`: broad, transparent demo hypotheses; not a diagnosis.
5. `medication_safety_agent_demo`: highlights unknown allergies/medications and refuses to invent drugs/doses.
6. `report_agent`: builds the draft report for clinician review.

Graph: `START -> intake_validation -> triage_demo -> [emergency_escalation OR summary_agent] -> differential_agent -> medication_safety_agent -> report_agent -> END`.

No RAG is included. Evidence retrieval is intentionally omitted rather than presenting unsourced demo text as medical evidence.

## Before real-world use
Add authenticated access control, secure persistence, approved LLM integration, clinically validated triage protocols, durable LangGraph checkpoints, clinician approval interrupt/resume, monitoring, evaluation, and privacy/security/legal/regulatory review. Add RAG only after an approved versioned corpus and evaluation plan exist.
